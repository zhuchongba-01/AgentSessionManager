Core Capabilities

化繁为简，只留真正值得细读的内容。

面向长上下文与复杂工程代码定制，把混乱的工具日志沉淀为可检索、可导出的本地知识库。

壹 · READ

两段式思维链与行号 Diff

默认收敛冗长过程，一键展开完整推理链（单块按需分页最高 2 MB）与红绿行号 Diff；超过 28 行的长代码块自动折叠预览，三态视图（全部 / 对话 / 改动）全链路联动。

贰 · SEARCH

SQLite FTS5 纯正文检索

后台批量事务增量构建纯正文索引，自动跳过系统注入块且不挤占阅读缓存；高亮摘录直达目标轮次，关闭开关即彻底清理索引文件。

叁 · GUARD

零抖动治理与安全边界

底栏原地多选零跳动、一键定位当前会话、原生另存为 `.md` 与路径胶囊直达；Rust 底层严守受控会话目录与防符号链接越界，绝不触碰项目源代码。
