核心特性

保留顺手的左右可拖拽分栏工作台，深度融合结构化对话阅读与本机安全治理

🔍

13 种 Agent 一站式纳管

原生支持 Codex、Claude Code、Gemini CLI、GitHub Copilot、DeepSeek、WorkBuddy、CodeBuddy、Kimi、OpenClaw、OpenCode、ZCode、Pi 与 Grok Build。

🧠

两段式思维链与实时过滤

按各 Agent 原生标签展示推理摘要、字数与耗时，支持按需拉取完整推理正文，工具栏一键显示/隐藏思考过程并同步导出。

🩹

步骤合并与内联行号 Diff

按 callId 自动配对工具输入输出，连续读/搜合并为 Explored，文件修改内置统一 Diff / 原始补丁切换与「全部 / 对话 / 改动」专注筛选。

⚡

SQLite FTS5 正文全文检索

开启「正文」开关即可在后台增量建立本地 FTS5 索引（仅索引非注入正文），展示高亮摘录卡片并一键直达目标对话轮次。

📤

原生另存为导出与路径胶囊

点击「导出 .md」弹出系统原生保存窗口自选位置；对话内本地路径渲染为路径胶囊，支持一键复制或在资源管理器中精准定位。

🧹

深度安全级联清理

进程运行守卫、符号链接防越界、子会话「先子后父」级联清理、50+ 批量知情核对与崩溃可恢复日志，绝不触碰项目源代码目录。
