Safety Architecture

把防误删与隐私边界，写进 Rust 底层。

所有文件操作与解析都在本机 Rust 核心内严格校验，完整安全承诺公开可审计。

01 / PATH BOUNDARY

受控根路径与防符号链接越界

删除前逐层校验规范路径、NTFS 重解析点与符号链接边界，任何指向项目仓库或系统目录的链接都会被直接拦截拒绝。

02 / PROCESS GUARD

进程守卫与先子后父级联清理

检测正在写入会话的活跃 Agent 进程与锁文件，按「先子代理后父会话」顺序安全回收，50+ 条批量操作强制知情核对。

03 / LOCAL FIRST

100% 离线单机，零云端遥测

无账号、无统计埋点、不上传任何对话或路径信息。所有索引、缓存与导出均在您的本机磁盘闭环完成。
