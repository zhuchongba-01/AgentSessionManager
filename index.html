专为长上下文与工程代码设计的阅读引擎

不止是日志查看器，而是把混乱的原始工具调用与思考流，整理成清晰、可查、可导出的工程文档。

两段式思维链 & 三态视图联动

按各 Agent 原生风格呈现推理块，默认单行展示摘要与耗时，点击按需分页拉取最高 2 MB 完整正文；顶栏「全部 / 对话 / 改动」三态切换实时同步会话内搜索、Markdown 复制与文件导出。

Safety & Privacy

本地优先，严守文件安全边界

面向开发者的历史对话往往包含代码片段与配置路径，我们将数据隐私与防误删视为核心底线。

只读解析，绝不触碰项目目录

仅扫描各 Agent 的受控会话数据根路径；清理操作严格限定在会话记录与边车元数据内，永不修改或删除您的源代码工作区。

进程守卫与防符号链接越界

执行删除前校验 NTFS 重解析点、符号链接边界与活跃锁文件，支持 50+ 条大批量知情核对与崩溃可恢复待清理日志。

纯离线单机，零云端遥测

无账号体系、无埋点上报、无对话上传；除用户手动点击或检查 GitHub 新版本外不产生任何外部网络请求。
