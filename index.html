为什么需要它

会话散落在各家目录里，文件名还是一长串 UUID —— 找回、恢复、清理都费劲

🔍

六种 Agent 一个界面

Codex、Claude Code、OpenCode、ZCode、Pi、Grok Build 的本地会话一站式扫描，不用再挨个翻目录。

🗂️

项目分组 + 缩略导航

会话按真实工作目录自动归组，紧凑型列表配合缩略导航，快速定位那场"调了半天"的对话。

📖

完整会话详情

按时间线阅读对话内容，一键复制恢复命令，跨平台终端直接恢复会话。

🧹

批量清理

残留会话识别、批量删除、Codex 桌面索引清理，磁盘和索引一起清爽。

🛡️

安全删除保护

删除全走系统回收站；真实工作目录默认保护，多 Agent 共享目录强制二次确认。

💻

纯本地运行

扫描、展示全部在本机完成，不上传任何会话内容。
