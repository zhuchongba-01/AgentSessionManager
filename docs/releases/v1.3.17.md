# v1.3.17

- 新增 DeepSeek Harness 本地会话浏览与选择性清理支持。
- 修复 DeepSeek 空白会话误显示、工作区与“未分组”归属不一致的问题，调整列表活跃时间计算。
- 修复 Codex 自定义侧边栏分区未被识别的问题，保留真实项目路径。
- 完善分支与子 Agent 会话的删除依赖检查，降低清理父会话时损坏关联历史的风险。
- 修复多轮短会话不显示左侧短线导航的问题，并改善虚拟列表高度变化后的显示判断。
- 增加版本一致性校验、回归测试和 Windows CI 检查。

## 安装

下载 `AgentSessionManager-Setup-v1.3.17.exe`，关闭旧版管理器后运行安装包。

删除会话前请退出对应 Agent，并备份重要记录。管理器清理会话不会删除项目工作目录。
